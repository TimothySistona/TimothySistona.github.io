## Favorite CPSC 120L Labs

* Lab 3 part 1

What I loved about lab 3 part 1 was the use of the Mifflin St Jeor equation to find out the estimate of someone’s BMR.
It was the first time we were using function definition in the main function for finding the BMR.
I loved how if we had the inputs correctly for the functions we would get the correct BMR outputs when calculating them.

* Lab 7 part 1

In lab 7 part 1 we were introduced to the use of strings which we had to use to incorporate streets, days, and times.
Trying to figure out how to implement that into the function was the challenging part but was very fun once we were able to figure it out.
It was satisfying seeing the expected outputs in the end matching the example.

* Lab 6 part 2

It was very interesting to know that lab 6 part 2 would be about blackjack.
While doing the lab we had some initial trouble with having the correct amount of arguments which gave us some runtime errors.
Once we figured it out it was cool to see the results of each test case working and finding the expected output working perfectly.
